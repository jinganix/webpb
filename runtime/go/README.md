# webpb Go runtime

Go runtime for messages generated by `webpb-protoc-go`.

```shell
go get github.com/jinganix/webpb/runtime/go
```

## Message contract

Generated messages implement `webpb.Message` and carry `webpb` tags that map
each field to its wire alias:

```go
type DemoRequest struct {
    Id   string `webpb:"a" json:"a"`
    Tags []string `webpb:"b" json:"b"`
}

func (m *DemoRequest) WebpbClass() string   { return DemoRequestClass }
func (m *DemoRequest) WebpbContext() string { return DemoRequestContext }
func (m *DemoRequest) WebpbMethod() string  { return DemoRequestMethod }
func (m *DemoRequest) WebpbPath() string    { return "/demo" }
```

## Encode / decode

```go
alias := webpb.ToAlias(message)   // map[string]any, ready for CBOR/JSON

target := demo.NewDemoRequest()   // proto2 defaults applied by the constructor
err := webpb.Populate(alias, target)
```

`ToAlias` walks nested messages, slices, maps, enums, and `[]byte`; unset
optional fields (nil pointers, slices, maps) are omitted, matching the
TypeScript runtime. `Populate` coerces the numeric/string/byte shapes produced
by CBOR and JSON decoders and only overwrites keys present in the payload.

Fields with explicit presence (`proto2` optional/required, `proto3 optional`,
oneof members) are generated as pointers so unset values stay distinguishable.
`proto2` defaults are applied by the generated `New*` constructors through the
package-local `webpbPtr` helper emitted as `webpb_helpers.pb.go`.

## Helpers

| Function | Purpose |
|----------|---------|
| `webpb.Of(m)` | Route metadata (`Class`, `Method`, `Context`, `Path`) |
| `webpb.Query(prefix, params)` | Query string with `encodeURIComponent` semantics |
| `webpb.Getter(data, "a.b")` | Read a dotted path from a decoded payload |
| `webpb.MapValues(record, fn)` | Map values of a string-keyed record |
| `webpb.NewSubTypeRegistry()` | `sub_type` / `sub_values` polymorphism dispatch |

## Oneof and enum aliases

Messages with a `oneof` get a `<Oneof>Case() string` discriminator returning the
name of the set member (empty when unset). Enums generated with
`(e_opts).go.auto_alias` (or file-level `go.auto_alias`) additionally emit a
`Const<Enum>` nominal alias type with `Alias()` / `Value()` conversions.

## Polymorphism

For messages declaring `(m_opts).opt.sub_type`, the generator emits a
`webpb.SubTypeRegistry` and a `<Base>FromAliasAny(data)` helper that picks the
concrete type from the discriminator value:

```go
message, err := demo.BaseFromAliasAny(alias)
```
